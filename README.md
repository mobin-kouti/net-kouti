# KoutiNet

وب‌سایت فارسی و راست‌چین KoutiNet با طراحی واکنش‌گرا و یک صفحه سه‌بعدی تعاملی.

## صفحات
- `index.html` صفحه اصلی و معرفی
- `3d.html` تجربه سه‌بعدی مبتنی بر Three.js

## اجرا
فایل‌ها را روی هاست یا GitHub Pages منتشر کنید. صفحه سه‌بعدی برای بارگذاری Three.js به اینترنت نیاز دارد.

## دامنه
پس از فعال‌سازی میزبانی، دامنه `koutinet.ir` را به سرویس میزبانی متصل کنید.
